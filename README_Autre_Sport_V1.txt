AUTRE SPORT — ÉCRAN PRINCIPAL V1 / GITHUB

Contenu :
- index.html : ajoute les deux scripts/styles de l’univers Autre sport.
- accueil-v1.js : branche la vignette « Autre sport » sur le nouveau module.
- sw.js : incrémente le cache de l’application (v99).
- autre-sport-v1.js et autre-sport-v1.css : écran et zones de navigation.
- autre-sport-accueil-v1.webp : l’image EXACTE validée avec les textes déjà intégrés.

Installation : déposer les 6 fichiers À LA RACINE du dépôt GitHub, en remplaçant les
fichiers homonymes. NE PAS supprimer les fichiers existants : cuisine, recettes,
Musculation, photos, tous les fichiers univers-* et leurs scripts restent nécessaires.

Disponible maintenant :
- vignette « Autre sport » du nouvel accueil ouvre cet écran ; retour à Mes univers ;
- bandeaux « Démarrer une activité », « Historique et statistiques », « Paramètres »
  ouvrent chacun un écran d’attente explicite ; navigation basse cliquable.

Non implémenté encore : GPS, chronomètre, choix des sports, véritable historique et réglages.
Ces fonctionnalités feront l’objet des prochains lots.

La photographie de l’écran comporte les mots et pictogrammes directement intégrés :
pas de second texte ni de dégradé supplémentaire ; les clics sont des zones transparentes.
