CRÉATEUR DE SÉANCES D'ÉTIREMENTS — V11

Ce ZIP est conçu pour être installé dans ton application GitHub.
Il complète la version V10 des séances d'étirements déjà validée.

CE QUI FONCTIONNE
- Donner un nom à une séance.
- Choisir entre Chronométrée et Libre.
- Régler durée des étirements, pauses et nombre de tours.
- Ouvrir une page distincte pour choisir les exercices.
- Rechercher et filtrer par catégorie.
- Ajouter, retirer et réordonner les exercices.
- Enregistrer, retrouver, modifier et supprimer des séances.
- Personnaliser les 4 séances proposées.
- Démarrer une séance, avancer et enregistrer la fin dans l'historique.

À SAVOIR
- La liste des exercices utilise les noms validés disponibles dans les fichiers du projet ; 26 exercices sont inclus comme base certaine, et les autres sont recherchés automatiquement dans les fichiers existants de l'application. Vérifie dans l'application que toutes les catégories sont bien complètes.
- Les nouvelles séances sont enregistrées sur l'appareil. La synchronisation automatique de ces nouvelles données entre appareils n'est pas encore intégrée.
- Le chronomètre dépend de l'activité du navigateur ; il n'offre pas encore les garanties d'une application Android native en arrière-plan.

INSTALLATION
1. Décompresse le ZIP.
2. Envoie les fichiers à la racine de ton dépôt GitHub, comme d'habitude.
3. Remplace index.html quand GitHub le demande.
4. Ne supprime aucun autre fichier.
5. Recharge l'application, puis teste « Étirements > Séances > Créer une séance personnalisée ».
