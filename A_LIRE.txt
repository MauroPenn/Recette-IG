SÉANCES D’ÉTIREMENTS — CORRECTIF V10

Ce ZIP corrige l’affichage des 4 bandeaux. La capture montrait toujours les anciennes images V8 : ce correctif actualise donc à la fois le nouvel écran V10 et les quatre anciens noms d’image V8, pour réduire le risque de voir encore l’ancien rendu.

Installation dans GitHub :
1. Décompresser le ZIP.
2. Ajouter TOUS les fichiers à la racine du dépôt (au même endroit que index.html).
3. Bien confirmer le remplacement de index.html et des quatre images V8 existantes.
4. Ne supprimer aucun autre fichier.
5. Sur PC, recharger la page entièrement (Ctrl + Maj + R). Sur le téléphone, fermer puis rouvrir l’application ; si nécessaire, l’ouvrir dans le navigateur et actualiser la page.

Ne pas effacer les données ni le stockage de l’application : les séances locales pourraient en dépendre.

Le créateur de séances reste à développer ; il s’agit du correctif visuel des quatre modèles.
