MON COACH – AJOUT SUR LA PAGE « MES UNIVERS » (V4)

Ce correctif remplace la version précédente pour intégrer la carte « Mon Coach »
avec le même gabarit que les autres cartes de la page d'accueil générale.
La carte est placée avant « Paramètres » quand cette carte existe.

Pour l'installer :
1. Ouvre le ZIP et décompresse-le.
2. Ajoute ses fichiers dans GitHub à la racine du dépôt.
3. Si GitHub le demande, remplace index.html.
4. Ne supprime aucun autre fichier.
5. Recharge l'application.

Cette version corrige :
- la hauteur de la carte sur PC,
- l'alignement dans la grille,
- l'affichage sur téléphone.
