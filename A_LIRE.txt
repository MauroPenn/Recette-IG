INSTALLATION
1. Décompresser ce ZIP.
2. Envoyer les 3 fichiers suivants à la racine du dépôt GitHub :
   - index.html
   - accueil-parametres-harmonise-v9.css

3. Remplacer index.html quand GitHub le propose.
4. Ne supprimer aucun autre fichier.
5. Recharger l'application, puis vérifier Paramètres sur PC et téléphone.

L'aperçu PNG est seulement inclus pour contrôle, il n'est pas nécessaire pour l'application.
