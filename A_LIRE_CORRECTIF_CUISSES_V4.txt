Ce ZIP contient seulement :
- les 3 bandeaux corrigés : 941 × 252 pixels ;
- le nouveau fichier de chargement des bandeaux (JS V4) ;
- index.html avec la référence au nouveau fichier JS.

Les 3 bandeaux reprennent les visuels validés : le paysage/fondu a été étendu

INSTALLATION GITHUB :
1. Décompresser le ZIP.
2. Ajouter les fichiers au niveau racine du dépôt GitHub.
3. Remplacer index.html (ne pas conserver l'ancien à la place).
4. Ne supprimer aucun autre fichier. Recharger ensuite l'application.

Le fichier JS V3 reste sur le dépôt mais ne sera plus chargé. Il est possible
qu'un navigateur conserve temporairement les anciennes images en cache ; les
noms V4 servent justement à éviter ce problème.
