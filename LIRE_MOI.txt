CORRECTIF DOS — ENCADRÉS V5

Ce fichier corrige uniquement les deux fiches de la catégorie Dos :
- Chat-vache
- Posture de l’enfant

Les contours dorés de chaque encadré sont maintenant entiers. Les fiches
occupent la hauteur du téléphone, sans étirer le personnage ni les textes.
Les boutons vidéo restent cliquables et indiquent que les vidéos sont à venir.

Pour installer : décompresser le ZIP puis ajouter à la racine de GitHub
le fichier index.html, les deux nouveaux fichiers et les 14 panneaux.
Remplacer index.html, enregistrer avec « Commit changes », puis rouvrir l’appli.

Les bandeaux d’accueil, les fiches des autres catégories, l’historique,
les séances et la synchronisation ne sont pas modifiés.
