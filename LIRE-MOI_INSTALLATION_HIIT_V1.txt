INSTALLATION SUR GITHUB
1. Décompresser ce ZIP sur votre ordinateur.
2. Dans le dépôt MauroPenn/Recette-IG, cliquer sur Add file > Upload files.
3. Envoyer les 9 fichiers applicatifs ci-dessous DIRECTEMENT À LA RACINE (pas dans un dossier).
4. Valider Commit changes et attendre Actions > pages build and deployment : Success.
5. Sur votre téléphone, fermer et rouvrir l'application si nécessaire.
