# Recettes IG bas & protéinées

Application web progressive (PWA) générée à partir de la bibliothèque Excel.

## Contenu
- 125 recettes
- 12 catégories
- recherche par nom ou ingrédient
- filtre catégorie et profil IG
- favoris stockés sur le téléphone
- ajout d'une photo personnelle par recette, stockée localement sur l'appareil
- fonctionnement hors ligne après la première ouverture
- installable sur l'écran d'accueil du téléphone

## Publication gratuite avec GitHub Pages
1. Créer un compte GitHub.
2. Créer un dépôt public, par exemple `recettes-ig`.
3. Importer tous les fichiers et dossiers contenus dans ce dossier.
4. Dans le dépôt : Settings > Pages.
5. Sous "Build and deployment", choisir "Deploy from a branch".
6. Choisir la branche `main` et le dossier `/ (root)`, puis Save.
7. GitHub affichera l'adresse du site après publication.

Important : le dépôt GitHub sera public avec l'offre gratuite. N'y mettre aucune donnée privée.
